# Skills Pivot Academy — One-Page Website

A responsive single-page static website containing the complete website content pack in anchored sections.

## Included
- One-page `index.html`
- Responsive navigation with mobile menu
- Deep navy + bright orange brand system
- Hero, trust bar, About, Mission/Vision/Accreditation, stats
- All six professional certificate programmes with modal detail panels
- Short courses & specialist training
- All ten physiotherapy short courses in expandable accordions
- Corporate training & consultancy
- Training areas
- Trainers / Experts
- Testimonials
- Student Success Stories
- FAQ
- Blog / Updates
- Enrol / Apply CTA
- Contact section + Google Maps embed
- WhatsApp enquiry form
- Newsletter interaction
- Privacy / Terms section
- Floating WhatsApp and Back-to-top controls

## Important content note
The supplied sitemap marks fees, schedules, entry requirements, trainer bios, detailed physiotherapy information, corporate brochure content and some testimonials as information still to be collected. This version therefore uses enquiry/TBC wording instead of inventing those details.

## Deployment
Upload the contents of this folder to the website public root (for example `public_html/`). No Node.js build step is required.
